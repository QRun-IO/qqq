# QQQ Dev Tools

Contributor tooling containing `CreateNewQBit`, which creates a QBit from a template repository. Read the command options and template assumptions before running it. This directory is not a published library in the QQQ 4.0 reactor; application setup is documented in the [sample](../qqq-sample-project/README.md) and the separate QBit templates.

QQQ 4.0 requires Java 21. See the [release and build instructions](../README.md) and [4.0 migration guide](../docs/migration/4.0.adoc).
