# QQQ Middleware - Slack

Slack middleware implemented by `QSlackImplementation`. It uses a configured `QInstance`, supplies Javalin routes through `getRoutes()` and includes helpers for Slack messages and widget output. Review its configuration, session setup and route contracts when wiring a Slack application.

QQQ 4.0 requires Java 21. See the [release and build instructions](../README.md) and [4.0 migration guide](../docs/migration/4.0.adoc).
